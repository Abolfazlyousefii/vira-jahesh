# پیام‌ها، اعتبارسنجی و خطاهای فارسی ویرا

## وضعیت فنی

- زبان اصلی و زبان جایگزین نصب جدید، `fa` است. در محیط‌های موجود نیز `APP_LOCALE=fa` و `APP_FALLBACK_LOCALE=fa` تنظیم شود.
- فایل `lang/fa/validation.php` حاوی پیام‌های سراسری قواعد اصلی Laravel و نام‌های فارسی فیلدهای معمول ماژول‌ها است. پیام‌های سفارشی با `validation.custom` یا ویژگی‌های نام‌گذاری‌شده تعریف می‌شوند.
- نام‌های داخلی فیلدها نباید در UI دیده شوند. در صورت افزودن فیلد جدید، کلید متناظر آن را به `validation.attributes` اضافه کنید. در فیلدهای آرایه‌ای از الگوی ستاره مثل `variantFeatures.*.name` استفاده کنید.
- فرم تنوع کالا به‌جای کلید داخلی `attributes` از `variantFeatures` استفاده می‌کند تا خطای Livewire زیر همان ورودی نمایش داده شود. پیام‌های خالی بودن نام و مقادیر ویژگی برای این فرم مستقل و مشخص‌اند.
- صفحه‌های خطای HTTP متداول `403`، `404`، `419`، `422`، `429`، `500` و `503` به همراه جایگزین‌های `4xx` و `5xx` در `resources/views/errors` فارسی شده‌اند. این صفحه‌ها خودکفا هستند تا حتی در صورت مشکل در فایل‌های Vite هم قابل نمایش باشند.
- فرم‌های مجموعه از `x-workspace.field` برای پیام خطای همان فیلد و `x-workspace.feedback` برای خلاصه خطا، موفقیت و وضعیت قابل دسترس استفاده می‌کنند؛ اعلان‌ها نباید اطلاعات محرمانه یا متن فنی استثنا را افشا کنند.
- نیازی به پکیج زمان اجرا نیست؛ امکانات بومی Laravel طبق `lang/fa` و `lang/fa.json` پیام‌ها را ترجمه می‌کنند. استفاده اختیاری از بسته‌های ترجمه عمومی در آینده مستلزم بازبینی تغییرات و قفل نسخه‌هاست.

## نکات امنیت و محیط اجرا

- در محیط واقعی `APP_DEBUG=false` بماند؛ خطاهای فنی در گزارش سرور ثبت می‌شوند، نه روی صفحه مشتری.
- پیام ۵۰۰ عمومی است؛ خطای مهم فروش، انبار یا پرداخت نباید نادیده گرفته شود.
- کلیدهای فارسی برای پیام‌های Livewire و پاسخ‌های HTTP کافی نیستند مگر این‌که ماژول‌های جدید نیز پیام‌های سفارشی را با نام فیلدهای درست صادر کنند.
- نمایش یک رشتهٔ فنی خام، به‌خصوص متن استثنا، در UI نباید به‌عنوان جایگزین ترجمه استفاده شود.

## تست و پذیرش

- `tests/Feature/PersianFeedbackTest.php`: پیام‌های اصلی اعتبارسنجی، ویژگی‌های کالای متنوع، صفحه‌های ۴۰۳/۴۰۴/۴۱۹/۴۲۹ و رمز عبور.
- `composer check`، `npm run test:ui`، `npm run build` و بررسی قالب‌های Blade و Cache مسیر باید سبز باشند.
- بازبینی دستی پیام‌های اشتباه با کیبورد، موبایل و صفحه‌خوان برای فرم‌های جدید توصیه می‌شود.
