# ویرا — پیاده‌سازی پوسته و میز کار V4

وضعیت: طرح V4 از سوی مالک تأیید شده است؛ یکپارچه‌سازی در Laravel بر پایه کد موجود انجام می‌شود.

## طراحی
- رنگ‌های ثابت **سرمه‌ای / فیروزه‌ای** و سطوح سفید ملایم؛ سایدبار راست، محتوای RTL و هدر همیشه ثابت.
- حذف تمام انتخاب‌گرهای رنگ و حالت تاریک از پنل؛ استفاده از فونت محلی Vazir و Lucide موجود.
- در نمای دسکتاپ بدنه اصلی ارتفاع viewport دارد؛ هر صفحه طولانی فقط در ناحیه محتوا اسکرول می‌کند. موبایل اسکرول طبیعی، منوی کشویی و قابلیت بستن با Escape و کلیک بیرونی دارد.
- پنج لینک اصلی و لینک‌های بیشتر زیر «مشاهده همه ماژول‌ها»، فقط با احراز وضعیت ماژول و permission نمایش داده می‌شوند. جست‌وجوی هدر در این مرحله فقط بین **بخش‌های مجاز** است، نه جست‌وجوی سراسری اطلاعات کسب‌وکار.
- منوی «ایجاد جدید» کاربر را به بخش ثبت مربوط هدایت می‌کند؛ تا زمانی که هر فرم رابط مستقیم مستقل نداشته باشد، رفتار آن به‌درستی «شروع ثبت» است.

## داده واقعی داشبورد
- سه کارت از بین ویجت‌های مجاز: فروش **ناخالص** امروز (از Sales)، مشتریان ثبت‌شده (Customers)، پیگیری‌های باز (CRM) و گزینه‌های جایگزین. واحد تومان صحیح است.
- نمودار ۷/۳۰ روز فروش **ناخالص** بر اساس روز محلی تهران، با مجموع سروری. حالت صفر **بدون نمودار ساختگی** است؛ محاسبات JavaScript صرفاً جهت رسم است.
- فاکتورهای واقعی اخیر از Sales با کانال ثبت، نه برچسب پرداخت خودکار/جعلی.
- پیگیری‌های سررسیدشده واقعی از CRM، بدون درز داده هنگام خاموش بودن ماژول یا نداشتن مجوز.
- ویجت‌های قدیمی حذف نشده‌اند و تحت «مشاهده سایر ویجت‌ها» قابل بازیابی هستند؛ نمایش/ترتیب/اندازه و ترجیحات کاربران حفظ می‌شود.

## مرز دامنه
- در این مرحله هیچ migration، سیستم حسابداری، درگاه، سفارش آنلاین یا صفحه جدید کسب‌وکار اضافه نشده است.
- نمودار نمایش فروش ناخالص است؛ مرجوعی برای گزارش خالص باید از گزارش رسمی Sales خوانده شود.
- طراحی گرافیکی صفحه عمومی Storefront تغییر نکرده است و فایل CSS این طراحی به `.v4-app` محدود است.

## کنترل کیفیت
- `composer check`: Pint و PHP Feature tests (شامل کنترل مجوز، حذف لینک ماژول خاموش و اعداد فروش واقعی).
- `npm run test:ui`: محاسبات هندسی نمودار شامل روزهای صفر و تک‌روزه.
- `npm run build`: ساخت Vite.
- برای تأیید نهایی مرورگر، مشاهده دسکتاپ و موبایل و اجرای تست‌ها در CI لازم است. اعداد HTML مستقل V4 هرگز مبنای داده عملیاتی قرار نگرفته‌اند.
