# فاز ۱A — Staging خصوصی اسکریپت Laravel Shop

در این مرحله یک انتقال اولیه و **غیراجرایی** انجام می‌دهیم: فایل‌های قالب DefaultTheme، فایل‌های پنل مدیریت قدیمی و دارایی‌های public/back فقط برای بررسی و تبدیل به مسیر خصوصی پروژه کپی می‌شوند. هیچ کد قدیمی در Laravel 13 اجرا، Route، یا publish نمی‌شود. هیچ دیتابیس یا فایل فعلی Storefront/ERP تغییر نمی‌کند.

## اجرای محلی در Windows / XAMPP

ابتدا ZIP اصلی Laravel Shop را روی دستگاه خودت داشته باش. از ریشه پروژه ویرا:

~~~powershell
php scripts/stage-laravel-shop.php "C:\path\to\175909-main-1.19.8.zip"
~~~

این فرمان فقط برنامه استخراج و تعداد فایل‌های انتخاب‌شده را نشان می‌دهد. پس از بررسی و اطمینان از حق استفاده و نگهداری کد، انتقال خصوصی را اجرا کن:

~~~powershell
php scripts/stage-laravel-shop.php "C:\path\to\175909-main-1.19.8.zip" --apply
~~~

محل پیش‌فرض: \`storage/app/private/legacy-shop-1.19.8/\` که تحت \`storage/app/private/.gitignore\` نادیده گرفته می‌شود. فایل \`manifest.json\` شامل مسیر، اندازه و SHA-256 هر فایل منتقل‌شده است. این خروجی را به مخزن عمومی اضافه نکن.

**در صورت وجود قبلی مقصد، فرمان از بازنویسی خودداری می‌کند.** برای انتقال مجدد، ابتدا پوشه قدیمی را بررسی و دستی جابه‌جا کن. ZIP داخلی \`webapp-v1.19.8.zip\` نیز پشتیبانی می‌شود.

## دامنه استخراج

- \`themes/DefaultTheme/\` شامل Views، CSS/JS، تصاویر و کدهای قالب برای تطبیق.
- \`resources/views/back/\` شامل قالب‌های پنل قدیمی برای تطبیق با WebsiteAdmin.
- \`public/back/\` شامل دارایی‌های پنل.

فایل‌هایی مانند \`.env\`، \`vendor\`، Migrationها، Routeهای ورود و تنظیمات Laravel قدیمی انتقال داده نمی‌شوند. حتی PHPهای داخل مسیر قالب **فقط به‌عنوان سورس غیراجرایی** ذخیره می‌شوند.

## گام‌های بعدی

۱. بررسی manifest در محیط توسعه و تعیین فایل‌های لازم برای نسخه فعال سایت.
۲. انطباق Viewها و Assetها با Vite و Namespaces فعلی، بدون CSS سراسری در ERP.
۳. انتقال تدریجی صفحات عمومی با Routeهای مجزا و تست.
۴. انتقال تدریجی کنترلرهای مدیریت به WebsiteAdmin با مجوزهای Fortify.
۵. قرارداد اتصال Product/Stock/Customer/Order با ماژول‌های موجود؛ هیچ دیتابیس موازی فعال نمی‌شود.

این ابزار برای ساخت بسته خصوصی اولیه است، نه نصب یا راه‌اندازی خودکار اسکریپت قدیمی. قبل از استفاده یا انتشار سورس اختصاصی، حق استفاده و بازنشر را بررسی کنید.
