# فاز ۱B — پیش‌نمایش اصل قالب DefaultTheme

## وضعیت
این مرحله HTML و قالب صفحهٔ اصلی `front::index` و `front::layouts.master` خود Laravel Shop 1.19.8 را از فضای خصوصی لوکال بارگذاری می‌کند. در نسخهٔ سازگار محلی فقط مسیر لینک‌ها و حالت استفاده از CSS/JS تغییر می‌کند. کد اختصاصی اسکریپت در GitHub عمومی منتشر نمی‌شود.

- صفحهٔ اصلی اصلی ویرا `/` و بخش `/shop` تا تأیید قالب جدید حفظ می‌شوند.
- مسیر جدید پیش‌نمایش: `/shop-preview`.
- مسیرهای آزمایشی محصولات: `/shop-preview/products` و `/shop-preview/products/{id}`.
- دادهٔ محصول مستقیماً از Catalog ویرا و فقط کالاهای فعال/منتشرشده خوانده می‌شود.
- منو، حساب کاربری و بلوک‌های محصول فعلاً واسط سازگار با Fortify و Catalog ویرا هستند؛ جدول و احراز هویت تکراری نداریم.
- صفحه اصلی از فایل اصلی اسکریپت استفاده می‌کند؛ برای جلوگیری از خطا، Widgetهای نیازمند دیتابیس قدیمی تا اتصال بک‌اند اصلی فعال نیستند.

## اجرا در Windows / XAMPP پس از ادغام PR

قبل از شروع، `storage/app/private/legacy-shop-1.19.8/manifest.json` باید موجود باشد (فاز ۱A).

```powershell
git switch main
git pull --ff-only origin main
php scripts/publish-laravel-shop-theme.php
```

دستور بالا فقط فهرست فایل‌هایی را که منتشر می‌شوند چاپ می‌کند. در صورت تأیید:

```powershell
php scripts/publish-laravel-shop-theme.php --apply
```

در `.env` اضافه کن:

```dotenv
VIRA_SHOP_PREVIEW_ENABLED=true
```

سپس:

```powershell
php artisan optimize:clear
composer dev
```

آدرس: `http://127.0.0.1:8017/shop-preview`

CSS/JS/تصاویر و فونت‌های اصلی قالب در `public/legacy-shop-theme/` قرار می‌گیرند و در Git Ignore می‌شوند. دو فایل Blade سازگار در `storage/app/private/legacy-shop-1.19.8/compat/views/` نگه‌داری می‌شوند. بقیهٔ فایل‌های اصلی اسکریپت بدون تغییر در Staging هستند.

## اگر خروجی قبلی وجود داشت
برای جلوگیری از آسیب، ابزار به‌صورت پیش‌فرض مقصد موجود را بازنویسی نمی‌کند. قبل از انتشار مجدد، نسخهٔ قبلی را بررسی و نام آن را تغییر بده؛ پوشه را کورکورانه حذف نکن.

## محدودیت‌ها و ادامه
این PR «راه‌اندازی کامل فروشگاه» نیست؛ در مرحله جاری فقط صفحهٔ اصلی و مرور محصولات با HTML/CSS/JS اصلی و واسط دادهٔ ویرا کار می‌کند. سبد خرید، تسویه، مدیریت اسلایدر و منوها، صفحات وبلاگ و تنظیمات سایت در PRهای جداگانه با backend و Permission مخصوص تکمیل می‌شوند. کد Laravel 10/Authentication و Migration قدیمی اجرا نشده است.

اگر پیش‌نمایش غیرفعال باشد 404 برمی‌گردد. اگر فعال باشد و فایل‌های لازم محلی منتشر نشده باشند 503 برمی‌گردد؛ در هیچ حالتی نباید مسیرهای ERP تحت تأثیر قرار بگیرند.

**فایل‌های اصلی اسکریپت (و فونت‌های دارای مجوز) را به مخزن عمومی GitHub Commit نکن.**
