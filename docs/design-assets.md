# منابع آمادهٔ طراحی

پنل از SVGهای آمادهٔ مجموعهٔ موجود **Lucide** استفاده می‌کند. آیکن‌های تصویر، تنوع، کارکنان، جست‌وجو و افزودن/حذف از همین مجموعه اضافه شدند؛ SVG سفارشی برای این کنترل‌ها ترسیم نشده و وابستگی یا CDN جدیدی اضافه نشده است.

- منبع رسمی: https://lucide.dev/icons/
- مجوز رسمی: https://lucide.dev/license
- نسخهٔ دقیق نصب‌شده: `package-lock.json`.
- متن کامل مجوز همان بسته، شامل بخش Feather: `public/licenses/lucide.txt`؛ این فایل باید همراه نسخهٔ توزیع‌شده حفظ شود.

این مجوز استفادهٔ تجاری را با حفظ متن حقوقی اجازه می‌دهد. تصویر اصلی کالا از خود مدیر دریافت می‌شود؛ تصویر نمونهٔ آزمون، بخشی از محتوای محصول یا کالای واقعی فروشگاه نیست. فایل SVG کاربر برای تصویر کالا پذیرفته نمی‌شود؛ قالب‌های مجاز JPEG، PNG و WebP هستند.
